# Password Lab - Project 1
Goal: Learn Python by building a test-password checker.
Version 1 features:
- Ask test password (input)
- Show length (len)
- Weak/medium/strong length (if/elif/else)
- Has number True/False (loop + isdigit)
Safety: test passwords only, local Kali only.
Not in Version 1: real passwords, hashing, saving, internet, GUI.
