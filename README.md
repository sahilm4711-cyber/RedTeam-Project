# RedTeam-Project
Learning red teaming step by step, with small Python projects.
Week 1:
- password-lab: test-password length and digit checker.
- system-audit: checks your own Kali machine only.
How to run:
- python3 password-lab/password_check.py
- python3 system-audit/system_audit.py
Safety: Test passwords only. Audit runs on your own machine only. No scanning other machines.
